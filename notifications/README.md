# GramMitraAI - Notifications & Alerting Service

This module handles:
- **SMS Severe Weather Alerts**: Critical advisories for heavy rainfall, hailstorms, and heatwaves.
- **IVR / Voice Calls**: Spoken local language automated phone alerts for farmers.
- **WhatsApp / Webhook Notifications**: Push notifications for downscaled agro-met advisories and irrigation recommendations.
