# GramMitraAI Documentation (SIH26074)

Comprehensive system documentation for the GramMitraAI platform.

## Architecture
- **Frontend**: React 19 + Vite + Leaflet with Google Maps Hybrid & Satellite
- **Backend**: Spring Boot 3 + Java 21 REST API
- **AI/ML Service**: FastAPI + XGBoost Ensemble + SHAP Explainability
- **Database**: PostgreSQL / PostGIS schema
- **GIS**: Panchayat & field polygon GeoJSON layers
